คู่มือผู้มาใหม่: Gen-Searcher

หน้าเว็บสรุปโครงสร้างระบบ สิ่งสำคัญที่ต้องรู้ และทางเรียนรู้ต่อสำหรับผู้เริ่มต้น

1) โครงสร้างหลักของ Repository

โปรเจกต์นี้เป็นระบบหลายองค์ประกอบ โดยแบ่งงานหลักเป็น SFT, RL workflow, image API server และ evaluation

Gen-DeepResearch-SFT/ Gen-DeepResearch-RL/ qwen_image_api_server/ KnowGen_Eval/

2) Mental Model การทำงาน

  1. Setup environment และ dataset
  2. เทรน SFT
  3. ตั้งค่า tools/services (search, browse summary, image API)
  4. เทรน RL agentic workflow
  5. รัน inference
  6. ประเมินผลด้วย KnowGen

3) สิ่งสำคัญที่ผู้มาใหม่ต้องรู้

  • เป็น multi-component repo: ต้องเข้าใจ dependency ระหว่างแต่ละส่วน
  • ใช้ทรัพยากรสูง และต้องพึ่ง external endpoints / API keys
  • evaluation แยกจาก training และอิงรูปแบบข้อมูลผล inference

4) ตัวอย่างเครื่องมือ + ทดสอบระบบ

มีตัวอย่าง sample_tool สำหรับ smoke test การเรียกใช้งาน tools ได้อย่างรวดเร็ว

cd Gen-DeepResearch-RL/rllm
PYTHONPATH=. python vision_deepresearch_async_workflow/tools/test_sample_tool.py

หากผ่านจะเห็นข้อความ sample_tool test passed

5) เรียนรู้อะไรต่อ

  1. อ่าน README.md ระดับ root ให้ครบ
  2. ลงลึก vision_deepresearch_async_workflow ฝั่ง RL
  3. ทำ data contract checklist ของ train/infer/eval
  4. รันชุดเล็กให้ครบหนึ่งรอบก่อน optimize
